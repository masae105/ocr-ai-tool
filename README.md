# OCR AI Tool

## 📌 概要

PDFや画像から文字を自動認識（OCR）し、抽出したデータをExcelへ自動入力するツールです。

請求書・領収書などの紙データを手入力する作業を削減し、業務効率化を目的として開発しています。

---

## 🎯 開発目的

日常業務では、PDFや画像化された書類から必要な情報を手入力する作業が多く発生します。

そこで、

* PDF・画像の読み取り
* OCRによる文字抽出
* データ整理
* Excelへの自動入力

までをPythonで自動化するツールの開発に取り組みました。

  - OCR金額異常候補を検出


- 複数請求書対応
  - 指定フォルダ内の請求書画像を一括処理
  - 複数データをExcelへ出力

  - 請求書情報シート
  - 明細シート

### Lv3：AIによる高度化

AIを活用し、より柔軟で精度の高い書類処理を目指します。

- AIによる書類レイアウト判定
  - 請求書ごとの項目位置を自動認識
  - 異なるフォーマットへの対応
  - 固定ルールに依存しないデータ抽出

- AIによる項目抽出
  - 会社名・日付・金額・商品情報の自動判定
  - 正規表現では対応が難しい書類への対応

- AIによるOCR結果補正
  - 誤認識文字の文脈判断
  - 商品名や金額の妥当性判定
  - 補正候補の自動提案

- データ自動分類
  - 請求書・領収書・レシートの自動判別
  - 書類種類に応じた処理分岐
