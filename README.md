# OCR AI Tool

## 📌 概要

PDFや画像から文字を自動認識（OCR）し、抽出したデータをExcelへ自動入力するツールです。

請求書・領収書などの紙データを手入力する作業を削減し、業務効率化を目的として開発しています。

---

## 🎯 開発目的

日常業務では、PDFや画像化された書類から必要な情報を手入力する作業が多く発生します。

そこで、

* PDF・画像の読み取り
* OCRによる文字抽出
* データ整理
* Excelへの自動入力

までをPythonで自動化するツールの開発に取り組みました。

- 複数請求書対応
  - 指定フォルダ内の請求書画像を一括処理
  - 複数データをExcelへ出力

- Excel出力改善
  - 請求書情報シート
  - 明細シート
  - 請求書形式への変換
  - 金額チェック

  ### Lv3：レイアウト解析・自動抽出機能

複数形式の請求書に対応するため、
OCR結果の特徴量と座標情報を利用した
レイアウト解析機能を実装しました。

対応内容：

- 請求書形式の自動判定（A/B/C）
- 形式ごとの抽出処理切り替え
- OCR座標情報による領域分類
- 抽出データのExcel自動出力

## 🔮 今後の課題・改善予定

### OCR精度向上

- 画像前処理の改善
- OCR認識精度の検証
- 補正辞書の拡充

現在実装しているレイアウト判定基盤をさらに発展させ、
AIを活用した柔軟な書類解析を目指します。


#### AIによる書類レイアウト認識

- 請求書ごとの項目位置を自動認識
- 固定ルールに依存しないレイアウト解析
- 未知フォーマットへの対応


#### AIによる項目抽出

- 会社名・日付・金額・商品情報の自動判定
- 正規表現では対応が難しい書類への対応


#### AIによるOCR結果補正

- 文脈を考慮した誤認識修正
- 商品名・金額の妥当性判定
- 補正候補の自動提案


#### 書類分類機能

- 請求書・領収書・レシートの自動判別
- 書類種類に応じた処理分岐
